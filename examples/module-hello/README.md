# Пример внешнего модуля «Привет»

Маленький модуль на Python без сторонних библиотек. Показывает всё, что нужно внешнему модулю:

- принимает события панели и проверяет их подпись, время и повторы;
- обращается к API панели своим ключом: читает свои настройки и пишет клиенту в бот;
- показывает свою страницу внутри админки и проверяет, кто из администраторов её открыл.

Что делает: новому клиенту отправляет приветствие, после оплаты — благодарность. Тексты задаются в настройках модуля в админке.

Формат описания и все подробности — в [docs/MODULES.md](../../docs/MODULES.md).

## Запуск рядом с панелью

1. В `module.json` адреса указаны на этот же сервер: `http://127.0.0.1:8090`. Такие адреса панель принимает, только если в `deploy/.env` есть строка `SN_EXT_MODULES_LOOPBACK=1` (после неё — `stealthnet restart`). Если модуль будет на другом сервере, замените их на `https://` с его доменом.
2. В админке: «Модули → Установить модуль», выберите `module.json`, проверьте права и подтвердите.
3. Сохраните ключ API и секрет подписи — панель покажет их один раз.
4. Запустите модуль на сервере (нужен Python 3.9 или новее):

```bash
SN_PANEL_URL=https://panel.example.com SN_API_KEY=snk_... SN_SIGNING_SECRET=whsec_... python3 hello.py
```

5. В карточке модуля нажмите «Проверить связь»: в журнале доставки появится «Принято, код 200».

Переменные:

| Переменная | Что это |
|---|---|
| `SN_PANEL_URL` | Адрес панели |
| `SN_API_KEY` | Ключ API модуля |
| `SN_SIGNING_SECRET` | Секрет подписи событий |
| `HELLO_HOST`, `HELLO_PORT` | Где слушать, по умолчанию `127.0.0.1:8090` |

Пример хранит обработанные события в памяти. Настоящему модулю стоит записывать `webhook-id` в базу, чтобы не выполнять событие дважды после перезапуска.
