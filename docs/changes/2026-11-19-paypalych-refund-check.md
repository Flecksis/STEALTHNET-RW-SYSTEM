# PayPalych: уведомления о возврате сверяются с API

- Статус и сумму возврата из уведомления PayPalych панель теперь перечитывает в API PayPalych. Если возврат там ещё не завершён, панель дождётся его по опросу.
- Платёж, к которому относится возврат или чарджбэк, панель берёт из счёта PayPalych. Уведомление с другим номером заказа отклоняется.
