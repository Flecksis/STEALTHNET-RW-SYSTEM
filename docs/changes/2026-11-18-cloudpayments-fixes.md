# CloudPayments: уведомления методом GET, СБП и подтверждённые возвраты

- Уведомления CloudPayments принимаются и методом GET, который стоит в кабинете CloudPayments по умолчанию. Раньше с этой настройкой проверка Check не проходила, и CloudPayments отклонял все оплаты.
- Возврат через CloudPayments считается выполненным только после подтверждения: по уведомлению Refund или по проверке статуса в CloudPayments. Если CloudPayments отклонит возврат (так бывает с возвратами по СБП), он отмечается отклонённым, а не возвращённым.
- Второй частичный возврат на ту же сумму больше не склеивается с первым, а возвраты при включённом тестовом режиме больше не теряются.
- У CloudPayments два способа оплаты: «Все способы» открывает страницу CloudPayments, как раньше, а «СБП» сразу ведёт в приложение банка, и такая оплата засчитывается даже без уведомления.
- В настройках CloudPayments подсказано, какие уведомления включить (Check, Pay, Fail и Refund), на какие адреса и с какими параметрами.
