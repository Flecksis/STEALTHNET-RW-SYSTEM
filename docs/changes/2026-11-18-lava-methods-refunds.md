# Lava: СБП, PayPal и возвраты

- Lava принимает оплату не только картой: в рублях ещё через СБП, в долларах ещё через PayPal. Нужные способы отмечаются в настройке Lava, у клиента появится кнопка на каждый.
- Возвраты и чарджбэки из кабинета Lava отмечаются у платежа в панели, если по почте покупателя и сумме ясно, какая это покупка. Если у покупателя несколько подходящих оплат, такой возврат виден только в кабинете Lava.
- Ключ вебхука в настройке Lava теперь обязателен, API-ключ вместо него больше не подставляется. Если поле было пустым, придумайте ключ и впишите его в панели и в кабинете Lava. В кабинете можно выбрать проверку по ключу или по логину и паролю (Basic), подсказка у поля объясняет, что отметить.
- Оплата по уведомлению Lava засчитывается только после проверки счёта в самой Lava. Покупатели, которые платят в рублях, видят страницу оплаты и письма Lava на русском.
