# Tribute: пополнение баланса и подписки в Telegram

- Tribute подключается в «Настройки → Оплата»: нужен API-ключ из Tribute («Настройки» → «API-ключи»), а в поле Webhook URL там же укажите адрес уведомлений панели. Список товаров и подписок панель загружает из Tribute сама.
- Товары Tribute пополняют баланс: отмеченные товары-суммы становятся кнопками пополнения. При покупке тарифа клиент платит самый дешёвый товар не меньше цены, заказ оплачивается с баланса сам, остаток остаётся на балансе. Кнопку Tribute видят только клиенты с привязанным Telegram.
- Подписки Tribute с автосписанием: привяжите срок подписки к тарифу и периоду. Новая подписка выдаёт тариф, каждое продление продлевает его ещё на период, отмена подписки оплаченный срок не забирает. Деньги за непривязанный срок идут на баланс.
- Если оплата пришла от покупателя, которого нет в панели, или Tribute вернул больше, чем осталось на балансе, это появится в «Деньги → Ждут решения» в группе «Деньги без решения»: решите вручную и закройте с пометкой. Донаты Tribute не засчитываются.
