# Подробнее об отброшенных скидках и лимите подписок в отчёте переноса

- Отчёт о переносе называет каждую ступень скидки за доп. устройства, которую не удалось перенести, и причину: ступень выше лимита доп. устройств, нулевая скидка, повтор того же числа устройств, скидка не растёт с числом устройств, больше десяти ступеней.
- Если в старой панели не было режима нескольких подписок, отчёт предупреждает: лимит подписок категории действует, только когда в «Тарифах» разрешено несколько подписок у клиента.
