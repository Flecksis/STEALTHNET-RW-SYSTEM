# Общий потолок писем с кодами

- В модуле «Почта» появилось поле «Писем с кодами в час»: столько писем с кодами входа, сброса пароля и смены почты каждого вида панель отправит за час на всю панель. По умолчанию — 300.
- Если почта идёт через сервер с маленькой дневной квотой (пароль приложения Яндекса, Mail.ru или Gmail), уменьшите это число, чтобы квота не кончалась и коды доходили до клиентов.
- Запросы кода с одной сети IPv6 /48 ограничены: не больше 15 за 10 минут.
