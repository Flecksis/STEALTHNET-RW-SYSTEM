# Перенос настроек почты из старой панели

- Перенос из STEALTHNET забирает настройки отправки писем. Для SMTP это сервер, порт, шифрование, логин и пароль, адрес и имя отправителя, для Resend — ключ API и адрес отправителя. Пароль и ключ сохраняются в зашифрованных секретах модуля «Почта».
- Если почта работала в старой панели, модуль «Почта» включается сразу. Вход на сайт остаётся по паролю, как раньше.
- Если в новой панели почта уже настроена по-другому, перенос её не трогает. Проверка покажет текущие настройки и настройки старой панели, а заменить их можно отметкой «Заменить настройками старой панели» перед запуском.
- Повторный перенос не включает почту, которую выключили после первого переноса.
- После переноса мастер напоминает отправить проверочное письмо в «Настройки → Почта и уведомления».
