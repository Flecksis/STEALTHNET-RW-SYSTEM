# Превью ссылок и robots.txt

- Сайт отдаёт настоящий `robots.txt`: сборщикам превью (Telegram, VK, WhatsApp и другим) открыто всё, поисковикам закрыты админка, кабинет и мини-приложение. При выключенном поиске закрыто всё, кроме сборщиков превью.
- Заголовок и описание сайта теперь есть и в тегах `twitter:`, которые читают некоторые сборщики превью.
- Когда сборщик превью открывает страницу, в журнале сервера появляется строка «сборщик превью ссылок открыл страницу». По ней видно, дошёл ли Telegram до сайта.
