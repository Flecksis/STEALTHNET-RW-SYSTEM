# Воронка по UTM-меткам: пришли, попробовали, подключились, оплатили

- У каждой метки на странице «UTM-метки» и в «Аналитика → Источники» — шаги воронки: сколько клиентов пришло с меткой за период, сколько из них взяли пробный период, подключились к VPN и оплатили. Доли — от пришедших, шаги считаются за всё время после прихода, переходы по ссылке — отдельным числом перед ними.
- Возле метки видно, сколько дней она идёт, и пометка «рано судить», пока ей меньше 30 дней. Список отсортирован по числу пришедших, сохранённые ссылки без пришедших показаны с нулями.
- Свои метки заводятся с любыми значениями, их можно изменить и удалить: цифры пришедших клиентов при удалении остаются. Метки из чужих ссылок видны с пометкой «не заведена», их можно сохранить кнопкой «Сохранить метку».
- Оплатившими считаются клиенты хотя бы с одним настоящим платежом: пробные и оплаты на ноль рублей больше не засчитываются.
- Периоды аналитики с первого числа по сегодня, например «12 месяцев», сравниваются с теми же днями на столько же месяцев раньше.
