# Отчёт об ошибке открывается готовой формой на GitHub

- «Открыть на GitHub» в «Сообщить об ошибке» открывает форму «Ошибка в панели»: описание, шаги, версия панели и Remnawave, страница и браузер уже стоят в своих полях, метка «ошибка» ставится сама.
- Если текст длинный, укорачивается самое длинное поле, а версия, страница и браузер остаются целыми.
