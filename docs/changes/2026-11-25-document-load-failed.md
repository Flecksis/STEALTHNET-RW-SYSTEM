# Страница документа сообщает о сбое загрузки

- Если данные сайта или текст документа не загрузились, на странице написано «Страница не загрузилась» и есть кнопка «Повторить». Раньше при сбое показывалась «Страница не найдена» или оставался пустой экран.
- «Страница не найдена» теперь значит только одно: такой страницы нет.
- При сбое сайт, кабинет и документы остаются на языке клиента. Раньше английские страницы переключались на русский и запоминали его.
