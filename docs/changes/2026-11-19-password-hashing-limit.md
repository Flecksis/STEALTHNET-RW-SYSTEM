# Проверка паролей не перегружает сервер

- Панель проверяет и сохраняет пароли не больше нескольких сразу: по два на ядро процессора, но не меньше 2 и не больше 16. Остальные входы ждут своей очереди.
- Если очередь не подошла за 10 секунд, вход отвечает «Сейчас слишком много входов. Попробуйте снова через 1 мин.».
- Обычные входы администраторов и клиентов этого не замечают: проверка одного пароля занимает доли секунды.
