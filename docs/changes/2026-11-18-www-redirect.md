# www ведёт на основной домен

- Если `www.example.com` указывает на тот же сервер, что и основной домен, установщик и `stealthnet domain` сами включают переадресацию с www на основной домен, сертификат для www выпускается автоматически.
- Если записи для www нет, в конце установки сказано, что добавить. После этого достаточно выполнить `stealthnet domain` ещё раз.
- Для своего веб-сервера в `deploy/proxy-snippet.txt` появляется готовый блок переадресации с www для Caddy и nginx.
- В установке без вопросов `SN_WWW=0` выключает переадресацию, `SN_WWW=1` включает её, не дожидаясь записи.
