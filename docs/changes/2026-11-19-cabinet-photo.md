# Кабинет не ищет фото, которого нет

- Кабинет узнаёт, есть ли у клиента фото из Telegram, вместе с профилем и запрашивает картинку только тогда, когда она есть. Лишних ошибок 404 в консоли браузера у клиентов без фото больше нет, в том числе после смены языка.
- Если фото ещё не загружено, панель ставит его в очередь, как раньше: оно появится в шапке кабинета при следующем входе.
- Когда клиент меняет фото в Telegram, кабинет показывает новое, а не старое из кэша браузера.
