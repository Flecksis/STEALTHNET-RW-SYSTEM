# Platega: частично возвращённый платёж не засчитывается как оплата

- Если панель ещё не засчитала оплату, а в Platega по ней уже был частичный возврат, панель больше не отмечает такой платёж оплаченным на полную сумму.
- О самом возврате Platega присылает отдельное уведомление, оно попадает в «Деньги → Ждут решения»: там решают, что делать с заказом.
- Частичные возвраты по уже оплаченным платежам засчитываются как раньше.
