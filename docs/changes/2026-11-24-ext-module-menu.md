# Страницы внешних модулей в боковом меню

- Включённый внешний модуль со своей страницей теперь есть в боковом меню админки, например «Установка нод». Раньше страница открывалась только из карточки модуля в «Модулях».
- Пункт меню видят администраторы с правом, которое указал модуль. Право «Модули» для этого больше не нужно.
- Меню обновляется сразу после включения, выключения, установки и удаления модуля.
