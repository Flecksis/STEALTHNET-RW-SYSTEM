# Перенос из старого бота: настройки, платёжки, админы и подарки

- Из STEALTHNET переносятся настройки: название сервиса и поддержка, пробный период, языки, документы (оферта, соглашение, инструкция), проценты рефералки, тексты и кнопки главного меню бота с эмодзи. Тексты, которым в новом боте нет места, лежат в отчёте — их можно вставить вручную.
- Ключи платёжных систем (ЮKassa, Crypto Pay, Platega, Heleket, Lava.top, ЮMoney, RollyPay, Overpay) переносятся, и платёжки сразу включаются. Не хватает ключа — платёжка останется выключенной, а в отчёте будет сказано, чего нет. В кабинетах платёжных систем нужно сменить адрес уведомлений на новый.
- Админы старой панели входят по прежней почте и паролю, разделы у них те же. Двухфакторный вход каждый настраивает заново.
- Переносятся заявки на вывод реферальных денег без повторного списания, неактивированные подарочные коды (получатель активирует тот же код) и авторассылки. Авторассылки приходят выключенными, чтобы клиенты не получили их дважды, пока работает старый бот.
- Настройки и платёжки переносятся только при первом переносе: повторный не затрёт правки в новой панели. Конкурсы, рулетка и история рассылок не переносятся — это видно при проверке.
