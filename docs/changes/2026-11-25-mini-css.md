# Свой CSS в конструкторе мини-приложения

- «Настройки → Мини-приложение»: внизу каждого раскрытого блока главной поле «CSS блока», в «Меню внизу» — «CSS меню внизу», в «Профиле» — «CSS профиля». Правила действуют только внутри своей части. Последняя строка списка — «Общий CSS» на все экраны мини-приложения.
- Превью показывает стили до сохранения. Ошибка подписана строкой и причиной, есть заготовки правил, загрузка картинки и «Сбросить». «Вернуть стандартное» убирает и CSS.
- Общий CSS действует и на экраны оплаты: после сохранения откройте «Тарифы» и пополнение и проверьте кнопки. Кабинет, лендинг, страница оплаты на сайте и админка не меняются.
- Классы, переменные цветов и примеры — в руководстве «Мини-приложение», раздел «Свой CSS».
