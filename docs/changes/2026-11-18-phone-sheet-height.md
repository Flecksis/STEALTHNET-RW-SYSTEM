# Меню «Ещё» на телефоне помещается на экран

- В админке на телефоне меню «Ещё» больше не уходит верхом за край экрана: высота считается по видимой части, а не по экрану без адресной строки браузера.
- Если пунктов больше, чем помещается, меню прокручивается, первый пункт виден.
- То же исправлено в меню действий в карточке клиента и в меню строки списка клиентов.
