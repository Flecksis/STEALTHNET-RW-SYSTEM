# «Администраторы»: как администратор входил в последний раз

- В «Настройки → Администраторы» рядом с датой последнего входа написано, как был этот вход: «по паролю» или «по паролю и коду». Раньше там стояло «вход по коду», если вход по коду включён сейчас, даже когда человек в последний раз входил только по паролю.
- Включён ли вход по коду сейчас, видно отдельно: «вход по коду включён».
- Способ записывается при каждом входе после обновления. У входов до обновления способ не известен, поэтому у них видна только дата.
- На телефоне кнопки администратора с включённым входом по коду («Новый пароль», «Сбросить 2FA», «Отключить») переносятся на следующую строку и больше не вылезают за край экрана.
