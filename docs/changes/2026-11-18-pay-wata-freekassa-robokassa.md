# WATA, Freekassa и Robokassa

- В «Настройки → Оплата» появились WATA, Freekassa и Robokassa — платёжки, которыми принимают оплату в Бедолаге, Remnashop, Minishop и remnawave-telegram-shop. У каждой есть подсказки, где взять ключи, адрес для уведомлений и кнопка «Проверить подключение».
- WATA: нужен токен доступа терминала, способ оплаты клиент выбирает на странице WATA. Оплата засчитывается только по уведомлению с подписью WATA и после сверки транзакции через API WATA. Есть тестовая среда и возвраты из панели.
- Freekassa: кнопки «СБП», «Карта», «SberPay» и «Все способы». Для первых трёх нужны API-ключ и IP-адрес сервера, для «Все способы» — секретное слово 1. Оповещения проверяются секретным словом 2, по желанию ещё и по адресам Freekassa. Возврат из панели засчитывается, когда Freekassa отметит заказ возвращённым.
- Robokassa: кнопки «Карта», «СБП», «SberPay», «T-Pay» и «Все способы», алгоритм хеша — как в настройках магазина, тестовый режим с тестовыми паролями. Проверка подключения подскажет, если алгоритм в панели не совпал с Robokassa. Для возвратов из панели нужен пароль №3.
- Если уведомление потерялось, панель сама спросит платёжку о статусе оплаты. Оплата засчитывается, только если сумма и валюта совпали со счётом.
