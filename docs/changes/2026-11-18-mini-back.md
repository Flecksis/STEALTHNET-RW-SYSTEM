# Мини-приложение: жест «назад» на Android

- В мини-приложении работает системный жест и кнопка «назад»: с любого экрана, кроме главного, они возвращают на предыдущий экран. На главном жест, как обычно, закрывает мини-приложение.
- Если экран открыт напрямую, без истории переходов, «назад» ведёт на родительский: из «Почты» в «Профиль», из «Тарифов» на главную.
