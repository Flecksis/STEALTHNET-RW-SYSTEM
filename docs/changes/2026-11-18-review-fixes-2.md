# Исправления после проверки: возвраты, недоплата и лимиты

- Возврат денег из админки работает и тогда, когда панель открыта по адресу без https.
- Счёт, недоплату по которому уже зачислили клиенту на баланс, нельзя отметить оплаченным вручную. Клиент оплачивает заказ с баланса, и деньги не выдаются дважды.
- Лимиты трафика: если панель перезапустилась посреди проверки, превышение ограничивается при следующей проверке.
- В мини-приложении экран вывода объясняет, почему вывести нельзя: денег пока нет или вывод не принимается.
