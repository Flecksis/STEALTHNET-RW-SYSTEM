# UTM-метки с сайта

- Метки `utm_source`, `utm_medium`, `utm_campaign`, `utm_content` и `utm_term` из адреса сайта запоминаются на 30 дней. Клиент, который потом регистрируется на сайте по почте, паролем или через Google и Apple, попадает в «Аналитика → Источники» с этой меткой.
- Кнопки лендинга, которые открывают бота, передают метку вместе с реферальным кодом, поэтому регистрация в боте после сайта тоже получает источник.
- Панель записывает переходы по меткам: запуски бота по ссылке с меткой, входы в мини-приложение по такой ссылке и заходы на сайт, один раз за сеанс браузера. Переходы считаются, пока включён модуль «UTM-метки».
- У заказов запоминается, где они оформлены: бот, мини-приложение, кабинет, админка или автопродление.
