# Шаги первого запуска на главной

- На новой панели блок «Нужно сделать» на главной больше не пишет «Срочных дел нет», пока не всё настроено. В нём видны шаги: «Подключите Remnawave», «Подключите бота» и «Создайте тариф», у каждого кнопка в нужный раздел.
- Выполненный шаг пропадает сам. Шаг «Создайте тариф» уходит, когда в продаже появляется хотя бы один тариф.
- Шаги видят только администраторы, которые могут их сделать: подключение — с правом «Настройки», тариф — с правом «Тарифы». На телефоне шаги тоже есть.
- Пока Remnawave не подключена, главная так и пишет: «Remnawave не подключена» вместо «Remnawave не отвечает».
