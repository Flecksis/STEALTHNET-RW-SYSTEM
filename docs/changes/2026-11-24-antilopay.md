# Antilopay: оплата картой, по СБП и через SberPay

- В «Настройки → Оплата» появилась Antilopay, она принимает рубли. В подсказках написано, какие ключи вставить и какой адрес указать для уведомлений. «Проверить подключение» проверяет ключи, ничего не создавая, и подсказывает, если поля перепутаны.
- У клиента одна кнопка с выбором на странице оплаты или отдельные кнопки: «СБП», «Карта», «SberPay», «Карта (Беларусь)» и «ЕРИП».
- Оплата засчитывается только по подписанному уведомлению, после сверки статуса и суммы с самой Antilopay. Если уведомление потерялось, панель спросит статус сама.
- Возврат делается из панели на всю сумму или на часть, если Antilopay разрешает частичный возврат по этому платежу.
