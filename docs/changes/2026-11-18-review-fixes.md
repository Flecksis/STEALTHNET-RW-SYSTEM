# Исправления после проверки: призы, рулетка, CloudPayments и лимиты

- Призы конкурсов больше не застревают. Победители без подписки, чьи дни ждут подписку, не задерживают выдачу денег, промокодов и дней остальным победителям.
- Рулетка не даёт крутить за покупку, пока по ней ждут возврат денег. Дни из рулетки доходят до подписки, даже если клиент закрыл мини-приложение во время вращения.
- CloudPayments: если первая карта не прошла и клиент оплатил другой, оплата засчитывается и подписка выдаётся.
- Лимиты трафика: два правила с одним сквадом работают как одно ограничение до конца последнего окна, и клиент больше не остаётся без сквадов. Правило с отключением срабатывает, даже если клиент уже переведён в сквад ограничения.
