# WATA: сверка терминала

- В настройках WATA появилось необязательное поле «ID терминала». Если его заполнить, панель принимает уведомления только этого терминала.
- «Проверить подключение» показывает, к какому терминалу относится токен, и предупреждает, если ID в настройках с ним не совпадает.
- Повторяющиеся уведомления, которые не прошли проверку, с одного адреса теперь ограничиваются, как у других платёжек со сверкой через API.
