# Временный пароль администратора открывает только смену пароля

- Пока администратор с временным паролем не задал свой, панель пускает его только на смену пароля и выход — и в админке, и через API. Раньше это проверял только экран админки.
- Как и раньше, при первом входе админка сама предлагает задать свой пароль.
