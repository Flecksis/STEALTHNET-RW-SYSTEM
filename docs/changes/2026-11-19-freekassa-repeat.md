# Freekassa: повторная оплата проверяется через API

- Если уже оплаченный счёт Freekassa оплатили ещё раз, панель зачисляет эту оплату на баланс только после того, как API Freekassa подтвердит заказ: тот же счёт, статус «оплачен», та же сумма.
- Неподтверждённая повторная оплата остаётся в журнале уведомлений с причиной. Если API Freekassa не ответил, она пришлёт оповещение снова. Первая оплата счёта проходит как раньше.
