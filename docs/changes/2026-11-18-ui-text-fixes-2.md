# Подсказки про адрес сайта и страницу Remnawave

- В «Настройки → Remnawave», режим «Страница Remnawave», убрана строка «Оформление страницы»: она ни на что не влияла. Оформление страницы подписки выбирается в самой Remnawave, а для «Взять из Remnawave» — в окне переноса приложений.
- Подсказки в шаблонах писем, в настройках мини-приложения и во входе через Google и Apple больше не отправляют задавать адрес сайта в «Общие»: он задаётся на сервере командой stealthnet domain, а в «Общих» только виден.
- В руководстве по почте описано, что при смене сервера SMTP, порта, шифрования или логина пароль нужно ввести заново.
