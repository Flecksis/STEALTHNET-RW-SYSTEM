# Первый релиз

Всё, что есть в системе на 17 ноября 2026 года.

### Установка и обновления

- Установка одной командой, из готового образа или из исходников. Установщик спрашивает только домен, а пароль базы, ключ шифрования и пароль владельца создаёт сам.
- HTTPS для домена выпускается автоматически. Пока сертификата нет, открывается страница-заглушка.
- Команда `stealthnet` на сервере: запуск, остановка, перезапуск, логи, состояние, обновление, новый пароль владельца, смена почты владельца и домена.
- Обновление из админки в «Настройки → Обновления»: перед запуском делается копия базы, при сбое — откат. Номер сборки виден в шапке рядом с кнопкой темы.

### Админка

- Главная с лентой событий, фильтрами и действиями прямо из ленты.
- «Клиенты»: сегменты, поиск, массовые действия и быстрые действия в меню «…». В карточке клиента — продление с отменой, смена тарифа, сброс трафика, новая ссылка подписки, устройства, история, баланс, сообщение через бота, сброс второго фактора.
- «Тарифы» с каналами продажи и применением изменений к подписчикам.
- «Поддержка»: поиск, непрочитанные, ответ клиента в боте попадает в его открытое обращение.
- «Инфраструктура»: ноды с состоянием и флагами стран, сквады, хосты Remnawave, оплата серверов.
- «Модули», «Промокоды», «Рефералы» с очередью выплат.
- «Настройки»: оформление, логотип и значок вкладки, описание сайта для поиска и превью ссылок, конструктор лендинга, бот (тексты, кнопки, картинки, документы), оплата, почта, кабинет и мини-приложение, администраторы с ролями, API-ключи, обновления.
- Меню сбоку или сверху, светлая и тёмная темы, отдельная раскладка для телефона.

### Бот

- Покупка и продление подписки, баланс, рефералы, поддержка.
- Главное меню показывает подписку: тариф, срок, трафик, устройства и баланс.
- Кнопка «Открыть приложение» запускает мини-приложение.
- Тексты, кнопки, картинки и премиум-эмодзи меняются из админки.

### Кабинет, мини-приложение и лендинг

- Кабинет на сайте: вход через Telegram или по почте, по желанию — с кодом из приложения-аутентификатора.
- Регистрация по почте тремя способами: по паролю без подтверждения (по умолчанию), кодом из письма через SMTP или через Resend.
- Подписка, подключение, устройства, история оплат и пополнение баланса.
- Мини-приложение в Telegram с теми же разделами, его можно выключить.
- Лендинг с каталогом тарифов, блоки настраиваются в конструкторе.

### Оплата

- Для каждого способа оплаты выбирается, где его показывать: в боте, кабинете или мини-приложении.
- GRAM: перевод TON с проверкой в сети и счётом в кошельке Telegram.
- Lava принимает рубли и доллары.
- Баланс можно выключить, тогда клиенты платят сразу за подписку.
- Возврат денег за невыданные заказы.

### Remnawave

- Пользователи Remnawave называются по нику в Telegram или почте, следующие подписки клиента — с `_2`, `_3`.
- По умолчанию у клиента одна подписка, новая покупка продлевает её, а переход на другую категорию объявляется до оплаты. Несколько подписок включаются переключателем.
