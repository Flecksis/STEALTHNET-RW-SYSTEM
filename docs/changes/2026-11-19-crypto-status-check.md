# Cryptomus и Heleket: проверка статуса только своего счёта

- Когда панель сама спрашивает Cryptomus или Heleket о статусе счёта, она принимает ответ, только если он о том же счёте, о котором спрашивали.
- Ответ о другом счёте не засчитывается: оплата остаётся неподтверждённой, а при повторной обработке уведомления из журнала видна причина.
