# Адреса запросов в админке и кабинете проверяются

- Админка, кабинет и мини-приложение не отправляют запрос, если часть адреса страницы уводит его в другой раздел панели. Такой запрос не уходит, на экране — «Неверный адрес запроса».
- Страницы встроенных и внешних модулей подставляют название модуля из адреса страницы только как одну часть пути запроса.
