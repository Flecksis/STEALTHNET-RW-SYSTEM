# Счета старой панели с ЮKassa сверяются по подтверждённому платежу

- Уведомление ЮKassa, для которого нет платежа в новой панели, проводит счёт старой панели, только если номер платежа ЮKassa, подтверждённый её API, совпадает с внешним номером этого счёта.
- Остальные платёжки ищут счета старой панели как раньше.
