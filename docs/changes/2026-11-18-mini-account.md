# Почта, пароль и вход по коду в мини-приложении

- В профиле мини-приложения появился блок «Аккаунт»: «Почта», «Пароль для сайта», «Вход по коду» и «Язык». Каждая строка открывает свою страницу. «Пароль для сайта» виден, когда на сайт входят по почте и паролю, «Язык» — когда включён английский.
- Клиент может добавить или сменить почту в мини-приложении и на странице «Безопасность» в кабинете. На новый адрес приходит код, почта меняется только после его ввода. Если включён вход по коду, для смены нужен код из приложения, если задан пароль для сайта — пароль. На прежний адрес уходит письмо о смене, а в истории клиента в админке появляется запись «Почта изменена».
- Почту, которая уже есть у другого клиента, привязать нельзя: клиент увидит понятную ошибку. Код действует 15 минут, частые запросы ограничены, как у кодов входа.
- Если в «Настройки → Почта» письма не отправляются, строка «Почта» объясняет это и смену не предлагает.
- Вход по коду включается в мини-приложении без QR-кода: кнопкой «Открыть в приложении» или копированием ключа. Маленький QR-код тоже есть, его можно отсканировать с другого устройства. Пароль задаётся и меняется там же, мини-приложение после этого остаётся открытым.
