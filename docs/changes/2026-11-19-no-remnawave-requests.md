# Новая панель не обращается к Remnawave до подключения

- Пока в «Настройки → Remnawave» не указаны адрес и токен, главная, «Настройки → Remnawave» и «Тарифы» не запрашивают у Remnawave счета нод, настройки подписки, оформления страницы и сквады. В консоли браузера больше нет ошибок 503, а в журнале сервера — записей ERROR на каждый заход.
- Счета нод на главной запрашиваются, только когда Remnawave отвечает.
- После сохранения подключения админка сразу узнаёт, что Remnawave подключена: перезагружать страницу не нужно.
