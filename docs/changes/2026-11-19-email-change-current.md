# Смена почты подтверждается кодом на текущий адрес

- Если у клиента нет ни пароля, ни входа по коду из приложения (или вход по почте — кодом из письма), то сменить привязанную почту в кабинете или мини-приложении можно только после кода, присланного на текущую почту.
- В разделе «Почта» появилась кнопка «Прислать код на …»: с этим кодом панель отправит код на новый адрес, как раньше.
- Добавить почту, если её ещё нет, и сменить её через бот можно как раньше.
