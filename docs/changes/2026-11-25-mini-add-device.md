# «Добавить» у устройств ведёт на докупку

- В мини-приложении на странице «Подключить» ссылка «Добавить» рядом с устройствами открывает докупку устройств. Раньше она вела на тарифы.
- Если тариф не продаёт дополнительные устройства, докупка выключена или подписка закончилась, ссылка ведёт на тарифы, как раньше.
