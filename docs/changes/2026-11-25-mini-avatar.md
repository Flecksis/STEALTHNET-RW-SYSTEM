# Аватар клиента в шапке мини-приложения

- «Настройки → Мини-приложение», блок «Шапка», новый переключатель «Показывать аватар клиента». Фото из Telegram стоит справа в шапке, нажатие открывает профиль. Если фото нет, виден значок.
- По умолчанию выключен: вид у клиентов не меняется, пока вы его не включите.
- Для своего CSS — класс `.mn-profile-avatar`, он же в заготовках правил шапки.
- Предложено в PR #21, автор Flecksis.
