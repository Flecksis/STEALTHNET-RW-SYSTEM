# Модуль из архива узнаёт об изменении настроек

- После «Сохранить» в настройках модуля, поставленного архивом, панель отправляет ему событие «Настройки изменены», как и модулям с файлом описания. Раньше событие не отправлялось, и новые значения модуль видел, только когда сам перечитывал настройки.
- Доставка видна в карточке модуля, в «Журнале доставки». Если модуль в этот момент не отвечает, панель повторит отправку.
- Модулям без адреса для событий, как и раньше, ничего не отправляется.
