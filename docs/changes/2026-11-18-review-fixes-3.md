# Исправления после проверки: звёзды, GRAM, автовозврат и уведомления

- Оплату звёздами, по которой Telegram уже вернул звёзды, нельзя провести снова, и заказ по ней не выдаётся. Если звёзды уже были возвращены, клиент получает о возврате одно сообщение.
- Перевод GRAM по счёту, который заменили новым счётом с тем же промокодом, находится в блокчейне и засчитывается.
- Если касса не ответила на автоматический возврат заблокированному клиенту, а клиента потом разблокировали, заказ ждёт проверки: деньги могли уже вернуться. Проверьте в кабинете кассы, затем отметьте возврат или нажмите «Повторить выдачу».
- «Уведомления платёжек»: карта для автоплатежей сохраняется и после ручной обработки, тела уведомлений маскируются надёжнее, поиск не заглядывает в старые незамаскированные тела.
- Уведомления администраторам в Telegram не теряются, если Telegram на время отказал: остаток уходит при следующей проверке.
