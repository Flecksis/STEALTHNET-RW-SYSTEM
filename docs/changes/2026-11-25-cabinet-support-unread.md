# Точка у «Помощи» в кабинете гаснет после прочтения

- В кабинете на сайте точка у «Помощи» горела, пока клиент не напишет в ответ или обращение не закроют, даже если ответ уже прочитан. Теперь она пропадает, как только клиент открыл переписку в кабинете или мини-приложении.
- В списке обращений новые ответы наверху с надписью «Новый ответ», прочитанные — «Есть ответ». Список обновляется сам.
- Ответ, после которого обращение сразу закрыли, теперь тоже отмечен как новый.
- В переписке, которую получает браузер клиента, больше нет внутреннего номера администратора и служебных сообщений.
