# Внешние модули на этом же сервере — только по разрешению

- Адреса этого же сервера (`localhost`, `127.0.0.1`, `[::1]`) внешним модулям теперь закрыты по умолчанию.
- Если модуль работает рядом с панелью на таком адресе, добавьте в `deploy/.env` строку `SN_EXT_MODULES_LOOPBACK=1` и выполните `stealthnet restart`.
- Без этой строки панель не установит и не обновит такой модуль, «Проверить связь» и страница модуля отвечают подсказкой, а события сразу помечаются «не доставлено».
- После перезапуска с этой строкой отправьте недоставленные события снова кнопкой «Отправить снова все» в журнале модуля.
