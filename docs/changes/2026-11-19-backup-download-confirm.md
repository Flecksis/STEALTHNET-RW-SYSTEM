# Скачивание копии подтверждается паролем

- Чтобы скачать резервную копию в «Настройки → Резервные копии», нужно ввести свой пароль, а если включён вход по коду — ещё и код из приложения. Ссылка на скачивание действует две минуты и один раз.
- Если вы скачивали копии скриптом по прямой ссылке, так больше не получится: сначала нужен запрос с паролем, потом скачивание по выданной ссылке. Копии в Telegram и S3 приходят как раньше.
- У переключателя «Резервные копии» в «Настройки → Администраторы» теперь написано, что в копии лежит ключ ко всем секретам панели.
