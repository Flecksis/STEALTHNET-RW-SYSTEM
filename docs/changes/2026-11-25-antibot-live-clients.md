# Антибот не мешает обычным клиентам

- Клиенты, перенесённые из старого бота или Remnawave, больше не считаются серией регистраций: пробный период, рулетка, конкурсы, промокоды и бонусы пригласившим работают для них сразу. Ложные отметки у таких клиентов снимаются при обновлении.
- Кнопка «Я не робот» срабатывает, даже если нажать её сразу или несколько раз подряд: в боте, кабинете и мини-приложении.
- Если один клиент привёл за сутки много новых аккаунтов Telegram, бонус и зачёт в конкурсе не даются только за них. Раньше вместе с ними отмечались и его обычные друзья, такие отметки снимаются при обновлении.
- Отметку «вариант адреса другого клиента» получает только тот, кто зарегистрировался позже. Лимит регистраций с одного адреса считает все регистрации за сутки, пробный период выдаётся клиенту один раз. Отказ антибота и кнопка «В меню» под сообщениями бота показываются на языке клиента.
- Из карточки клиента открывается журнал антибота по нему одному. Снятие отметки записывается в «Журнал действий», удалённые клиенты не остаются в списке отмеченных.
