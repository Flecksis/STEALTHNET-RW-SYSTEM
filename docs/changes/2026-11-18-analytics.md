# Бизнес-аналитика

- Новый модуль «Бизнес-аналитика»: включается в «Модулях», в меню появляется «Аналитика». Раздел видят администраторы с правом «Деньги».
- Вкладки «Деньги», «Клиенты», «Удержание», «Платёжки» и «Источники»: выручка и MRR по месяцам, средний чек и сколько в среднем приносит платящий клиент, новые, продлившие, вернувшиеся и ушедшие клиенты, покупки после пробного периода, удержание по месяцу первой покупки.
- Платёжки сравниваются по обороту, доле, неоплаченным счетам и возвратам; у каждой раскрываются способы оплаты внутри неё.
- Период — 3, 6, 12 месяцев или всё время, отбор клиентов по UTM-метке, выгрузка в CSV для Excel.
- Месяцы считаются по часовому поясу из настроек Remnawave, звёзды Telegram показываются отдельно от денег.
