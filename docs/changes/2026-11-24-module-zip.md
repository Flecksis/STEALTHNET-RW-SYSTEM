# Модули из архива ставятся прямо в админке

- В «Модули → Установить модуль» теперь можно загрузить zip-архив модуля. Панель проверит его и обычными словами покажет, что модуль получит в панели, сколько памяти и процессора займёт и выходит ли в интернет, а потом сама запустит его на этом сервере. SSH, команды, свой HTTPS и копирование ключей не нужны.
- Модули из архива ставит, обновляет и удаляет только владелец, с паролем и кодом из приложения. Архивы, подписанные STEALTHNET, помечены «подпись проверена». Архив без подписи ставится только с отметкой, что вы доверяете автору, а изменённый после подписи не принимается.
- Модуль работает в своём контейнере: корень только для чтения, пределы памяти и процессора, без доступа к базе панели, файлам сервера и Docker, без портов наружу. Его страница открывается внутри админки через панель.
- В карточке модуля из архива — состояние, память, журнал, перезапуск, обновление новым архивом с возвратом прежней версии при сбое и удаление с отдельной галочкой для данных.
- Если сервер обновлялся только из админки, выполните один раз `sudo stealthnet update`, чтобы помощник на сервере научился ставить модули. Запретить ставить модули и управлять ими из админки можно командой `stealthnet modules off`: уже запущенные модули при этом продолжают работать.
