# Overpay: оплата картой и СБП

- Overpay подключается в «Настройки → Оплата»: ID проекта, логин и пароль API и сертификат клиента. Как перевести файл .p12 от Overpay в текст для поля сертификата, написано в подсказке под полем.
- В «Способах оплаты» Overpay можно включить кнопки «Карта», «СБП» и «Все способы». По кнопке «Все способы» клиент выбирает способ на странице Overpay. Если способы не отмечены, у клиента одна кнопка «Банковская карта».
- Оплата засчитывается, только когда Overpay подтверждает заказ и списанную сумму. Если уведомление потерялось, панель сама проверит счёт.
- Возвраты через Overpay работают целиком и частями. Если Overpay проводит возврат не сразу, панель сама проверит, прошёл ли он.
- Адрес для уведомлений в кабинете Overpay указывать не нужно: панель передаёт его вместе с каждым счётом.
