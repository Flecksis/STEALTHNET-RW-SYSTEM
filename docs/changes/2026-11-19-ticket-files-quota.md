# Место для файлов в обращениях ограничено

- Файлы одного клиента в обращениях занимают не больше 100 МБ, все файлы обращений — не больше 5 ГБ. Оба значения меняются в настройках модуля «Файлы в обращениях».
- Когда место кончается, клиент видит «Место для файлов закончилось» и может описать вопрос текстом. Файлы от поддержки принимаются как раньше.
- Файлы закрытых обращений теперь по умолчанию хранятся 180 дней. Если срок в настройках модуля не меняли, файлы обращений, закрытых раньше, удалятся в течение часа после обновления; переписка останется.
- Чтобы хранить файлы дольше, до обновления поставьте свой срок в «Хранить файлы закрытых обращений, дней», например 3650. Сохранённый срок не меняется, после обновления можно поставить и 0 — хранить бессрочно.
