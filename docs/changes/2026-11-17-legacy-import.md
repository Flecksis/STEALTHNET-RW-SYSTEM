# Перенос из другого бота

- Новый раздел «Настройки → Перенос из другого бота»: клиенты, подписки, балансы, тарифы, промокоды, рефералы, история оплат и обращения из STEALTHNET 7.x и из бота Бедолаги. На пустой установке подсказка есть и на «Главной».
- Нужен только файл резервной копии старого бота — на экране написано, где его взять. Проверка перед переносом ничего не записывает: показывает, что перенесётся, а что нет и почему.
- Подписки привязываются к пользователям той же панели Remnawave, поэтому ссылки у клиентов не меняются. Старый бот не трогается, клиентам ничего не приходит.
- Перенос идёт в фоне, страницу можно закрыть. Перед переключением можно загрузить свежую копию и перенести ещё раз: добавится только новое. В конце — отчёт о проблемах и что сделать дальше.
