# Первый вход по коду закрывает прежние входы

- Если клиент зарегистрировался по паролю, почту не подтверждал, а потом вошёл кодом из письма, прежние входы на сайте закрываются, а пароль удаляется. Пароль можно задать заново через «Забыли пароль».
- Это действие видно в журнале действий: «Прежние сессии и пароль сброшены при первом входе по коду из письма».
