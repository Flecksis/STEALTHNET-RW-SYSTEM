# Пароль почты и адреса внешних модулей

- Если в «Почте» поменять сервер SMTP, порт, шифрование или логин, пароль нужно ввести заново. Панель не отправляет сохранённый пароль на другой сервер. Ключ Resend всегда уходит только в Resend.
- Перенос из старой панели: если в «Почте» уже сохранён пароль, а сервер SMTP в старой панели другой, почта не перенесётся, и в отчёте мастера будет причина «введите пароль заново». Замена с отметкой «Заменить настройками старой панели» работает как раньше.
- При обновлении внешнего модуля из файла с другим адресом для событий или страницы окно показывает, какой адрес сейчас и какой станет. Обновление проходит только после подтверждения нового адреса, а смена записывается в журнал действий со старым и новым адресом.
