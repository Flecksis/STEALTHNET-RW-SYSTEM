# Лимиты на коды из письма и смену пароля

- Если на одну почту за сутки ввели 30 неверных кодов из письма (вход или восстановление пароля), вход по коду на эту почту закрывается примерно на сутки. Верно введённый код в счёт не идёт.
- Смена пароля в кабинете: не больше 10 попыток за 15 минут на клиента.
