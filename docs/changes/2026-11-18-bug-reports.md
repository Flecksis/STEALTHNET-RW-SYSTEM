# Сообщить об ошибке из админки

- В меню профиля и в «Ещё» на телефоне появился пункт «Сообщить об ошибке».
- В форме нужно описать, что случилось, как это повторить и что ожидалось. Версия панели и Remnawave, страница, браузер, размер экрана, язык и время добавляются сами, по галочке можно приложить последние сбои скриптов из вкладки.
- Перед отправкой показан весь текст задачи, его можно поправить. Почты, ссылки, адреса серверов, телефоны и токены заменяются на [скрыто].
- «Открыть на GitHub» открывает готовую задачу в открытом репозитории разработчиков, нужен аккаунт GitHub. Если GitHub не открылся, текст можно скопировать кнопкой «Скопировать текст».
