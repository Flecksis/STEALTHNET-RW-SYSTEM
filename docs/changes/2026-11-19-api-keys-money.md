# Ключи API и права на деньги

- Сменить почту клиента, проверить и установить обновление панели и открыть настройки вебхука Remnawave с секретом можно только после входа в админку. Ключом API это сделать нельзя, как и раньше нельзя было выдать клиенту пароль.
- Личный процент реферала меняется с правом «Деньги», как и весь раздел «Рефералы».
- Без права «Деньги» карточка клиента не показывает сумму, удержанную под возвраты.
