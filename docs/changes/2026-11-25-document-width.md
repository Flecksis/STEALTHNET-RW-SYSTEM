# Документы на сайте занимают всю ширину

- Страница документа (политика, оферта и другие) на компьютере идёт во всю ширину сайта: края текста совпадают с шапкой, подвалом и блоками лендинга. Раньше текст занимал около двух третей и справа оставалось пустое место.
- В таблицах слова больше не рвутся по буквам: широкая таблица прокручивается сама, вбок страница не уезжает. Длинные ссылки в ячейках переносятся.
- На узких телефонах длинные названия документов в заголовке и в подвале переносятся по слогам.
- Превью в «Настройки → Документы» выглядит так же.
