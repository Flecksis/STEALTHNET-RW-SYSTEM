# Перенос клиентов из Remnashop и Minishop

- В «Настройки → Перенос из другого бота» появились Remnashop и Minishop. Мастер сам узнаёт бота по файлу и подсказывает, где этот файл взять.
- Remnashop: подойдёт файл `db_backup_….sql`, который бот присылает по кнопке «Бэкап», или автоматическая копия из папки `backups` на сервере бота. Minishop: полный файл `minishop-….zip` из раздела «Система → Бэкапы» в админке Minishop.
- Переносятся клиенты, подписки с привязкой к пользователям Remnawave, тарифы, промокоды, рефералы и история оплат, у Minishop — ещё баланс и обращения. Повторный перенос не создаёт дублей.
- Баллы и личные скидки клиентов, партнёрский баланс, сохранённые карты и ключи платёжек не переносятся: проверка покажет их до переноса, а суммы и клиенты будут в отчёте.
