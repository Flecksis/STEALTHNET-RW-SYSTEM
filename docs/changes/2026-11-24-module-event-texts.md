# Панель не обещает модулю события, которых не будет

- После «Сохранить» в настройках внешнего модуля админка пишет «модуль получит событие об изменении», только если событие поставлено в очередь. Выключенному модулю, модулю без адреса для событий и при сохранении без изменений — просто «Настройки сохранены».
- Карточка модуля без адреса для событий больше не пишет «Получает события». Так же исправлены окно установки архива без пути для событий и страница после установки файла описания.
- Файл описания, в котором есть события, а адрес пустой (`"webhook": null` или `""`), не принимается: панель просит указать адрес. Раньше такой модуль устанавливался, и его события не доставлялись.
