# CisPay и ParityPay: оплата картой, по СБП и криптовалютой

- В «Настройки → Оплата» появились CisPay и ParityPay. В подсказках написано, где в кабинете взять ID магазина и ключи и какой адрес указать для уведомлений. Кнопка «Проверить подключение» проверяет ключи, ничего не создавая.
- CisPay принимает СБП, карту и криптовалюту, в долларовой установке — только криптовалюту. ParityPay принимает СБП и карту. У обеих можно включить отдельные кнопки способов или одну кнопку с выбором на странице оплаты.
- Оплата засчитывается только по подлинному уведомлению, после сверки с самой платёжкой и только если сумма совпала со счётом. Тестовые платежи CisPay из «Песочницы» засчитываются, только если это включено в настройках. Уведомления видны в журнале в «Деньгах».
- Возвраты CisPay делаются из панели на всю сумму или на часть, кроме оплат криптовалютой. У ParityPay возвратов через API нет: деньги возвращает её поддержка.
- При переносе из старого STEALTHNET оплаты CisPay и ParityPay попадают в историю под этими платёжками, ключи ParityPay переносятся сами, ключи CisPay нужно вставить заново, а уведомления на старые адреса продолжают засчитываться, пока в кабинете не сменят адрес на новый.
