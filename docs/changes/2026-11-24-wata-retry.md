# WATA: «Обработать ещё раз» работает для оплаченных уведомлений

- В «Уведомлениях платёжек» кнопка «Обработать ещё раз» на оплаченном уведомлении WATA всегда отвечала «Повторить пока нельзя». Теперь панель спрашивает у WATA статус по номеру заказа, и оплата проводится.
- Если оплата уже засчитана, деньги второй раз не зачислятся.
