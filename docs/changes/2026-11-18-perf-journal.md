# Быстрый поиск по уведомлениям платёжек и рассылки

- Поиск в «Деньги → Уведомления платёжек» отвечает сразу даже на большом журнале: по номеру платежа, заказа, счёта в кассе и по тексту уведомления.
- Охват рассылки «Подписка закончилась» считается в несколько раз быстрее.
- Кнопка «Отправить» у рассылки на большую аудиторию отвечает быстрее: список получателей собирается без лишней проверки.
- При обновлении панель включит в базе стандартное расширение PostgreSQL для поиска по тексту (`pg_trgm`) и построит один индекс по журналу уведомлений, обычно за секунды. Если расширение недоступно, обновление всё равно пройдёт, а поиск по журналу будет работать без индекса.
