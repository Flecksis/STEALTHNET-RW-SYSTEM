# Перенос: выгрузка до 20 ГБ

- Файл выгрузки старого бота теперь может весить до 20 ГБ, а не до 2 ГБ. Большую выгрузку лучше сжать в `.sql.gz`: она станет в 5–10 раз меньше и загрузится быстрее.
- Если на диске сервера не хватает места, панель скажет об этом сразу, до загрузки, с размером файла и свободного места.
- В готовом блоке для nginx лимит поднят до 20 ГБ и добавлено `proxy_request_buffering off`, чтобы файл шёл сразу в панель без промежуточной копии.
