# Аналитика: «Этот месяц» работает и после полуночи

- Период «Этот месяц» и другие периоды до сегодняшнего дня больше не дают ошибку «Период не может заканчиваться в будущем», когда в браузере уже наступил новый день, а по часовому поясу панели ещё нет. Конец периода просто обрезается до сегодняшнего дня панели.
- Дни в «Аналитике» считаются по поясу из «Настройки → Общие → Часовой пояс Remnawave», об этом теперь сказано в подсказке. Если вы работаете по Москве, выберите там UTC+3.
