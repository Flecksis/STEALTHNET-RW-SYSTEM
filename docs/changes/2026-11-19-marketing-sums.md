# Суммы в «UTM-метках» и «Подарках» — только с правом «Деньги»

- Выручка по UTM-меткам и суммы оплат подарков видны только администраторам и API-ключам с правом «Деньги».
- С одним правом «Маркетинг» разделы работают как раньше, но без сумм: в метках нет выручки, в подарках не видна оплата, в выгрузке меток нет столбцов с выручкой.
