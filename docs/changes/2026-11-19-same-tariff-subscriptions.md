# Подписки одного тарифа различимы в боте

- Если у клиента две подписки одного тарифа, бот подписывает их кнопки с именем пользователя в Remnawave, как мини-приложение: «Стандарт · anna · до 18 декабря» и «Стандарт · anna_2 · до 18 декабря». Без имени — «Подписка 1», «Подписка 2».
- Так подписаны все списки выбора подписки в боте: «Подписка», продление, промокод на дни, докупка и выбор при заполненной категории.
- В карточке клиента вкладки «Подписка 1», «Подписка 2» идут в том же порядке, что в боте, кабинете и мини-приложении: сначала оформленная раньше. По умолчанию по-прежнему открыта самая важная подписка.
