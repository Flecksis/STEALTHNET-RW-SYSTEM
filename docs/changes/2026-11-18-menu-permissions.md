# Меню админки по правам администратора

- Разделы модулей в меню видны только тем, у кого есть нужное право: «Маркетинг» — для рассылок, промокодов, промо-ссылок, подарков, конкурсов и рулетки, «Деньги» — для рефералов и аналитики.
- Раньше «Поддержка» и «Наблюдатель» видели в меню эти разделы и попадали на экран «Раздел доступен администраторам с правом…».
