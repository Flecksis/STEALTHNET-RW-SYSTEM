# Клиенты не видят подробностей ошибок Remnawave

- Если Remnawave не ответила или ответила ошибкой, кабинет и мини-приложение показывают клиенту общий текст «Сервис VPN сейчас недоступен. Попробуйте через несколько минут.» — без адреса панели и текста её ответа.
- В админке подробности ошибок Remnawave видны как раньше.
