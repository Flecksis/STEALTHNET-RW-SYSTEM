# Настройки без прав: только открытые разделы

- В «Настройках» слева видны только разделы, на которые у администратора есть права. Раньше «Поддержка» по прямой ссылке видела весь список и получала «недостаточно прав».
- По прямой ссылке на закрытый раздел настроек админка показывает один экран «Нет доступа» и говорит, какое право нужно. Запросов к закрытому разделу она не делает.
- Администратор только с правом «Резервные копии» попадает сразу в «Резервные копии».
