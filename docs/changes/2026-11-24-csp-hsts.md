# Заголовки HSTS и CSP

- На запросы по HTTPS панель отвечает заголовком HSTS: год браузер открывает её домен только по HTTPS. Поддомены не затрагиваются, выключить можно строкой `SN_HSTS_MAX_AGE=0` в `deploy/.env`.
- В админке действует политика CSP: скрипты загружаются только с самой панели, во фреймах открываются только страницы внешних модулей. Внедрённый в страницу чужой скрипт браузер не выполнит.
- На лендинге, в кабинете, мини-приложении и на странице оплаты политика пока в режиме отчётов: браузер ничего не блокирует, а о нарушении сообщает в журнал панели строкой «CSP: браузер сообщил о нарушении политики страницы».
- Включить политику везде сразу — `SN_CSP=all`, оставить только отчёты и в админке — `SN_CSP=report`. Подробно — в руководстве по установке, раздел «HSTS и CSP».
