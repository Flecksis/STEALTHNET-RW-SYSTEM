# Английский язык на лендинге, странице оплаты и в письмах

- Лендинг показывает стандартные тексты на языке посетителя: по его выбору, иначе по языку браузера. Переключатель языка — в шапке лендинга. Тексты, которые вы написали в конструкторе, остаются вашими.
- Страница оплаты по ссылке открывается на языке клиента, которому выставлен счёт.
- Письма с кодом входа и сменой пароля, уведомления на почту и подвал рассылок с отпиской приходят на языке клиента. Страница отписки — тоже. Текст самих рассылок остаётся вашим.
