# Резервные копии без Docker: правильная подсказка

- Если панель запущена без Docker и папка для копий не задана, «Настройки → Резервные копии» больше не советуют `sudo stealthnet update`: такой команды на этом сервере нет. Раздел просит указать папку в переменной `SN_BACKUP_DIR` и перезапустить панель.
- Если в папку нельзя записывать, подсказка называет папку и говорит, что дать права на запись пользователю панели или выбрать другую папку.
- При установке через `install.sh` всё по-прежнему: подсказка предлагает `sudo stealthnet update`.
