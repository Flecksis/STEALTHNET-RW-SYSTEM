# Свой CSS в конструкторе лендинга

- В «Настройки → Лендинг» у каждого блока появилось поле «CSS блока»: правила действуют только внутри него. Последняя строка списка — «Общий CSS» для всей страницы. Превью справа сразу показывает ещё не сохранённые стили на компьютере и телефоне, в светлой и тёмной теме.
- Редактор с номерами строк называет ошибку и строку («Строка 7: не закрыта скобка {»), вставляет заготовки правил для частей блока и загружает картинки для фона на ваш сервер. «Сбросить» очищает поле, «Вернуть стандартный лендинг» убирает и CSS.
- Стили действуют только на лендинг: кабинет, мини-приложение, документы и админка не меняются. Сайту они отдаются отдельным файлом с вашего домена, `SN_CSP=all` продолжает работать.
- `@import`, `javascript:`, картинки и шрифты с чужих сайтов панель не принимает и объясняет почему. Пока поля пустые, лендинг выглядит как раньше. Подробно, со списком классов — в руководстве, раздел «Лендинг».
