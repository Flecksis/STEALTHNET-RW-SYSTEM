# Спорные оплаты: выдача и промокоды

- «Пересчитать и выдать» больше не продлевает подписку второй раз. Если заказ уже применён и пользователь есть в Remnawave, действие запрещено: используйте «Повторить выдачу» или «Отметить выданным». Если пользователя в панели удалили, пересчёт создаст его заново.
- Код на дни, активация которого оборвалась из-за сбоя сервиса, считается использованным, повторно его не активировать. Спорные случаи решаются через поддержку.
- Если клиент оплатил счёт со скидкой уже после того, как промокод закончился, заказ выдаётся по цене счёта, без ручной проверки.
- В истории платежей клиента виден способ, который он выбрал при оплате, например «СБП».
