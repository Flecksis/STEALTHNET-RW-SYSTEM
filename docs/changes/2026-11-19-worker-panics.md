# Сбой одной задачи не останавливает фоновую работу

- Если фоновая задача (выдача заказа, рассылка, сверка с Remnawave и другие) упала из-за ошибки в коде, панель отмечает её неудачной и повторяет по обычным правилам.
- Остальные задачи продолжают выполняться. Раньше такой сбой останавливал всю фоновую работу до перезапуска.
