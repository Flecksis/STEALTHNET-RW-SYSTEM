# Вход администраторов и доверенные прокси

- Если почту владельца подбирают и с нового адреса войти не получается, на сервере есть команда `stealthnet unlock-login`. Она снимает блокировку входа, пароль не меняется. С `--ip <ваш адрес>` вход с этого адреса 30 дней не закроется, даже пока подбор продолжается.
- Когда вход администратора по коду из приложения закрывается после неверных кодов, бот пишет об этом в группу администраторов: кто, сколько кодов и с какого адреса. Это новый вид «Безопасность входа» в «Настройки → Уведомления в Telegram», он включён сразу.
- В `SN_TRUSTED_PROXIES` можно записать адрес сети Docker вместе с маской, как его показывает `ip addr`, например `172.18.0.1/16`. Панель запустится и будет доверять всей частной сети `172.18.0.0/16`, а в журнал напишет предупреждение.
- `0.0.0.0/0` в `SN_TRUSTED_PROXIES` по-прежнему разрешено, но панель предупреждает об этом при запуске и на главной странице админки: с такой настройкой любой посетитель может подменить свой адрес.
