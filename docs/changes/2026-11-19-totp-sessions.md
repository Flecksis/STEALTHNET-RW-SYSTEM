# Включение входа по коду завершает другие входы

- Когда администратор включает вход по коду из приложения (2FA), все его остальные входы в админку завершаются, кроме того, из которого он его включил.
- У клиента в кабинете и мини-приложении так же: после включения 2FA остальные входы нужно повторить.
