# Внешний модуль: исправленный файл проверяется заново

- В «Модули → Установить внешний модуль» можно поправить файл описания и выбрать тот же файл снова: панель перечитает его и проверит заново. Раньше оставалась старая ошибка, и помогала только перезагрузка страницы.
- Так же работает «Выбрать другой» после успешной проверки.
