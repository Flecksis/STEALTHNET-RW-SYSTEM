# Доп. устройства у подписок, выданных вручную

- В карточке клиента теперь можно поменять число доп. устройств у подписки, выданной вручную или перенесённой из другого бота. Раньше админка отвечала ошибкой, потому что у такой подписки нет оплаченного периода.
- Новое число сразу уходит в Remnawave: лимит устройств пользователя меняется, лишние устройства удаляются, начиная со старых.
