# Подписи платёжек

- Кнопка ЮMoney называется по настроенному типу оплаты: «Карта» при оплате картой и «ЮMoney» при оплате из кошелька.
- Кнопка Platega без выбранных способов называется по способу из настроек: «СБП», «Карта», «SberPay» и т. п.
- В списке платёжных систем обновлены описания: у Lava, Platega, ЮKassa, ЮMoney, CloudPayments и Heleket перечислены способы, которые они теперь принимают.
- У переключателя «Списывать с сохранённой карты через ЮKassa» появилась подсказка: карты сохраняются, только когда в настройках ЮKassa включены «Автоплатежи».
