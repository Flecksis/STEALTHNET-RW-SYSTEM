# Привязка подписок к пользователям Remnawave вручную

- В карточке клиента у подписки, которая не связана с пользователем Remnawave или чьего пользователя в Remnawave больше нет, появилась кнопка «Привязать к пользователю Remnawave». Окно найдёт пользователя по имени, ссылке подписки, Telegram ID или почте и сравнит его с подпиской: срок, трафик, устройства, сквады и статус.
- Если у клиента нет подписки, которая есть в Remnawave, её можно добавить кнопкой «Добавить из Remnawave»: срок и лимиты берутся из Remnawave, тариф подбирается так же, как при синхронизации, автопродление выключено.
- Пользователя, который уже привязан к другой подписке, панель не привяжет и покажет эту подписку со ссылкой на её клиента. Привязка и добавление записываются в историю клиента, в Remnawave ничего не меняется.
- Проверка переноса из другого бота перечисляет подходящих пользователей у подписок, которые не удалось сопоставить однозначно, и подсказывает, как их добавить. Для ненайденных подписок она советует «Забрать из Remnawave» в «Настройки → Remnawave → Синхронизация».
