# Перенос правил тарифов из старой панели

- Категория, в которой старая панель разрешала одну подписку на клиента, переносится с лимитом в одну подписку этой категории.
- Скидки за дополнительные устройства переносятся в лесенку скидок тарифа. Ступени, которые новая панель не может повторить — где скидка не растёт с числом устройств, больше 99 % или сверх десяти ступеней, — перечислены в отчёте о переносе.
- Если категории и тарифы уже переносились раньше, повторный перенос добавит лимит и скидки, только когда эти поля ещё пустые. Снятые вами лимит и скидки он не вернёт.
