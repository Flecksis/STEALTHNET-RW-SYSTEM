# Перенос из Remnawave Telegram Shop и Chill Remna bot

- В «Настройки → Перенос из другого бота» появились ещё два бота: Remnawave Telegram Shop и Chill Remna bot. Мастер сам узнаёт бота по файлу и подсказывает, где взять копию.
- Chill Remna bot: подходит бэкап из «Система → Бэкап базы» (файл .bak, мастер спросит пароль бэкапа), файл базы bot.db или pg_dump. Переносятся клиенты с почтой и паролем кабинета, балансы, рефералы, тарифы с ценами, подписки, промокоды на дни и история оплат. Второй аккаунт в панели переходит отдельной подпиской.
- Remnawave Telegram Shop: подходит копия базы pg_dump, команда для неё есть в подсказке мастера. Переносятся клиенты, рефералы, подписки и история оплат. Цены этот бот хранит в .env, поэтому тарифы нужно завести вручную — мастер об этом напомнит.
- Подписки привязываются к пользователям, которые уже есть в Remnawave, ссылки у клиентов не меняются. Старые реферальные ссылки обоих ботов продолжают работать.
