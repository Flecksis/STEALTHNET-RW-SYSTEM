# Антибот: сколько обращений с одного адреса пропускать

- «Клиенты» → «Антибот» → «Настроить»: появился блок «Сколько обращений с одного адреса пропускать за 10 минут» — по почте, через Telegram и на странице проверки. Числа по умолчанию прежние: 5, 10 и 60, после обновления ничего не меняется.
- Если под одним адресом у вас много людей (мобильный оператор, общежитие, офис) и они видят «Слишком много попыток», поднимите число.
- Регистрация по паролю теперь ограничена и по сети IPv6 — так же, как письма с кодом.
- Один клиент может сдать не больше 30 ответов капчи за 10 минут: дальше панель просит подождать и не спрашивает сервис капчи.
- При выключенном модуле «Антибот» действуют обычные числа.
