# MulenPay, PayPalych, Kassa.ai и AuraPay: оплата после переезда из других ботов

- В «Настройки → Оплата» появились MulenPay, PayPalych (сейчас называется Pally), Kassa.ai и AuraPay. В подсказках написано, где в кабинете платёжки взять ключи и какой адрес указать для уведомлений. Кнопка «Проверить подключение» проверяет ключи и магазин, ничего не создавая.
- Клиент платит картой или по СБП. У PayPalych и AuraPay можно включить отдельные кнопки «СБП», «Карта» и «Все способы», у Kassa.ai — «СБП», «Карта» и «SberPay». У MulenPay способ выбирается на странице оплаты.
- Оплата засчитывается только по подлинному уведомлению и только если сумма совпала со счётом. Уведомления MulenPay и PayPalych панель дополнительно сверяет с самой платёжкой. Все уведомления видны в журнале в «Деньгах».
- Возвраты из панели: MulenPay — только на всю сумму, PayPalych и Kassa.ai — на всю сумму или на часть. Возвраты PayPalych через API включает её поддержка. У AuraPay возврата через API нет: деньги возвращает поддержка AuraPay.
- Тестового режима в панели у этих платёжек нет. У Kassa.ai он включается в кабинете магазина, и тестовые оплаты засчитываются как настоящие: после проверки выключите его.
