# Почта для клиентов из Telegram без писем

- Новый переключатель «Привязывать почту без кода» в «Настройки → Почта и уведомления», блок «Вход на сайт по почте». По умолчанию выключен. Действует, только пока письма не отправляются: клиент из Telegram указывает почту и пароль в боте, мини-приложении или кабинете и входит на сайт без кода из письма.
- Такая почта не проверена, поэтому это только логин вместе с паролем: писем и рассылок на неё нет, войти кодом или сменить пароль по ней нельзя. В карточке клиента она отмечена «не подтверждена».
- Когда подключите SMTP или Resend, клиент увидит «Почта не подтверждена» и подтвердит её кодом. Подтвердить можете и вы: сохраните тот же адрес в карточке клиента.
- Если почты нет и привязать её нельзя, мини-приложение и кабинет пишут «добавить», а не «сменить».
