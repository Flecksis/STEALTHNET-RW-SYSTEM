# Антибот не тормозит панель

- Пока сервис капчи отвечает, панель и бот работают как обычно: медленный ответ Cloudflare или Яндекса больше не задерживает остальные запросы.
- Отказ антибота в рулетке больше не занимает лишние соединения с базой: панель не останавливается, когда отмеченных клиентов много.
- На базах в сотни тысяч клиентов проверка клиента стала быстрее в десятки раз. При обновлении строятся два индекса, на 300 тысяч клиентов это около секунды.
- Старые запросы входа по коду из письма удаляются через неделю и тогда, когда через Telegram на сайт никто не входит.
