# Вход в кабинет по коду: адрес, повтор и смена почты

- После «Прислать код» кабинет пишет, на какой адрес ушёл код и сколько он действует.
- Кнопка «Отправить ещё раз» присылает новый код. Она становится доступна через минуту, рядом идёт обратный отсчёт.
- «Изменить почту» возвращает к вводу адреса: если адрес набран с ошибкой, больше не нужно переключать вкладки.
