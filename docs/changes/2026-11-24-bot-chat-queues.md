# Медленный ответ одному клиенту не задерживает бота

- У каждого чата теперь своя очередь. Если ответ одному клиенту ждёт Remnawave или Telegram, остальные получают ответы сразу. Раньше такой ответ держал всех, кто попал с ним в одну из восьми общих очередей.
- Сообщения одного клиента по-прежнему обрабатываются по порядку, а флудящий чат упирается в свой предел и не занимает места других.
- Бот обрабатывает до 64 обновлений одновременно вместо 8. Число меняет переменная `SN_BOT_CONCURRENCY`: её поднимают, если Remnawave подолгу отвечает сразу многим клиентам.
- Зависший запрос к Telegram обрывается через 20 секунд и больше не держит чат.
