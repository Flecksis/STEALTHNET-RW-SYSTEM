# Регистрация по паролю с подтверждением почты

- В «Настройки → Почта и уведомления», блок «Вход на сайт по почте», у входа по паролю появился переключатель «Подтверждать почту при регистрации». По умолчанию он выключен, на работающих панелях регистрация идёт как раньше.
- Когда подтверждение включено, клиент после ввода почты и пароля получает письмо с кодом, а аккаунт появляется только после ввода кода. До этого клиента нет: ни пробного периода, ни учёта в метках и рефералах. Метка, реферальная ссылка и язык переходят в аккаунт при подтверждении.
- По форме регистрации нельзя узнать, есть ли почта в базе: ответ одинаковый, а владельцу занятой почты приходит письмо с подсказкой войти или сменить пароль.
- Включить подтверждение можно, только когда письма отправляются. В «Шаблонах писем» появились письма «Код для регистрации» и «Почта уже зарегистрирована».
- Реферальная ссылка сайта теперь засчитывается и при обычной регистрации по почте и паролю или по коду из письма.
