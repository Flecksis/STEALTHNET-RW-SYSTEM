# Команда stealthnet cert: выпустить сертификат заново

- `stealthnet cert` показывает, куда указывает домен (и www, если включена переадресация), и предупреждает, если ни один адрес не принадлежит серверу.
- Если сертификата нет, команда сразу повторяет выпуск, не дожидаясь паузы между попытками, и ждёт результата. Если не вышло, называет причину по журналу Caddy: домен не в DNS, закрыт порт 80, ограничение Let's Encrypt или проверку получил другой сервер.
- `stealthnet cert --force` заменяет уже выпущенный сертификат, например если браузер ругается на него.
- В конце установки и в подсказке «сертификат пока не выпущен» теперь указана эта команда.
