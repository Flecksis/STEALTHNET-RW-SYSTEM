# Антибот проверяет подписки по промо-ссылкам, как пробный период

- В режиме «Просить подтвердить» отмеченный аккаунт перед подпиской по промо-ссылке нажимает в боте кнопку «Я не робот», как перед пробным периодом. После кнопки подписка оформляется сразу, а кто уже подтверждал раньше, проходит без неё.
- В режиме «Не давать пробник и бонусы» подписку по промо-ссылке такой аккаунт не получает, бот отвечает нейтрально и предлагает написать в поддержку. В режиме «Только отмечать» и для аккаунтов без отметки ссылка работает как раньше.
- Сначала проверяется сама ссылка: выключенную, просроченную или уже использованную клиент видит сразу, без кнопки.
- Если снять отметку вручную, подписка по ссылке выдаётся сразу.
- В журнале антибота новые записи «Попросили подтвердить перед промо-ссылкой» и «Подписка по промо-ссылке не выдана» с названием ссылки, фильтр «Промокоды» теперь называется «Промокоды и ссылки». Подтверждения кнопкой показываются в фильтре того, что подтверждали: пробный период, промокоды и ссылки, рулетка или конкурсы.
