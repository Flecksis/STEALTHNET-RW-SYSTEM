# Перенос из старого бота: проверено на настоящих резервных копиях

- Подписки старой STEALTHNET находятся в Remnawave 3.x, даже если в копии остались только uuid из Remnawave 2.x. Перенос сверяет Telegram, почту и имя пользователя так, как их задавала старая панель: `ник`, `ник_1`, `ник_2`. Несколько подписок одного клиента с одинаковым сроком теперь различаются, а не уходят в «подходят несколько».
- Пользователя Remnawave с чужим Telegram ID или чужой почтой перенос не привязывает по одному совпадению имени. Если в старой панели два клиента вели к одному пользователю, подписку получает один из них, а в отчёте написано, с кем она была общей.
- Проверка заранее предупреждает о двух вещах. Первая — подозрительно большие балансы, дороже десяти самых дорогих тарифов: они переносятся как есть и идут первыми в отчёте. Вторая — в подключённой Remnawave не нашлось ни одной подписки: похоже, подключена не та панель.
- Давно истёкшие подписки, которые старая панель уже скрыла от клиентов, не переносятся. В отчёте видно почты, записанные в старой панели с ошибкой, и реферальные связи, которые не перенеслись: пригласившего нет или связь замкнула бы круг приглашений.
- Выгрузки на несколько гигабайт читаются примерно вдвое экономнее по памяти.
