# Капча Cloudflare Turnstile и Яндекс SmartCaptcha в антиботе

- В «Клиенты → Антибот → Настроить» появился блок «Капча»: Cloudflare Turnstile или Яндекс SmartCaptcha, ключ сайта и секретный ключ. Секрет хранится зашифрованным, ответ капчи всегда проверяет сервер, один ответ принимается один раз и только для своего клиента и действия. Сервер проверяет ответ у сервиса капчи напрямую, не через исходящий прокси.
- Перед пробным периодом капча спрашивается всем или только подозрительным. В кабинете она появляется на месте кнопки пробника, в боте кнопка «Пройти проверку» открывает страницу проверки, после неё пробник выдаётся сразу.
- Регистрация по почте в кабинете тоже просит капчу: в форме регистрации по паролю, в том числе с подтверждением почты, и перед отправкой кода при входе кодом из письма.
- Если сервис капчи не отвечает, пробный период и регистрация не выдаются, клиент видит просьбу повторить через минуту, а в настройках антибота видна последняя ошибка.
- Без капчи кнопка «Я не робот» в кабинете и мини-приложении требует от браузера короткую вычислительную задачу. Скрипт в два запроса, который просто повторял ответ сервера, её больше не проходит.
