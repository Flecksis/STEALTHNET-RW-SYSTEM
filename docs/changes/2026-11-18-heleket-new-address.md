# Heleket снова принимает оплату

- Heleket перенёс API на api.heleket.hk: старый домен heleket.com заблокирован у регистратора с 13 ноября, и счета Heleket не создавались. Панель теперь обращается к новому адресу.
- В настройках Heleket появилось необязательное поле «Адрес API»: если Heleket снова сменит адрес, его можно вписать без обновления панели.
- Оплата засчитывается, как только Heleket присылает статус «оплачено» или «оплачено с переплатой», даже если уведомление помечено как промежуточное.
- При недоплате клиент может доплатить недостающее в том же счёте, а не теряет деньги на закрытом счёте.
- Если Heleket отклоняет счёт, в панели виден его текст ошибки, а не код HTTP 422.
