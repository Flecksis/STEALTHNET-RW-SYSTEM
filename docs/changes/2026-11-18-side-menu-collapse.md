# Боковое меню админки сворачивается после перехода

- Раньше после выбора пункта в боковом меню оно оставалось раскрытым, пока не кликнуть по странице. Теперь меню сворачивается, как только мышь уходит с него.
- С клавиатуры меню по-прежнему раскрывается при переходе клавишей Tab, а пока открыто меню профиля, боковое меню остаётся раскрытым.
