# Переключатели на телефоне: каждая кнопка видна отдельно

- В переключателях админки на телефоне (фильтры подарков, промокодов, промо-ссылок, конкурсов, решений по рефералам, выбор вида промокода и конкурса) у каждой кнопки появилась тонкая рамка, выбранная по-прежнему залита.
- Если вариантов четыре, а экран узкий, они встают в два ряда, чтобы подписи не вылезали за кнопку.
