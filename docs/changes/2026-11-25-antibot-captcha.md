# Капча: перепутанные ключи, сбои и обрывы связи

- Ключи капчи, перепутанные местами или взятые у другого сервиса, не сохраняются: панель подсказывает, какой ключ нужен в каком поле.
- Если сервис капчи не отвечает или секретный ключ не подошёл, об этом сказано вверху страницы «Клиенты → Антибот», в том числе после перезапуска и в каждой копии панели. Сообщение гаснет после первой удачной проверки.
- Ответ Cloudflare Turnstile сверяется строже: он принимается только для той проверки, для которой капча показана.
- На странице проверки при обрыве связи можно повторить на месте, после «Изменить почту» при регистрации капча спрашивается заново, а если домен панели не вписан в настройки капчи, клиент видит, что она настроена с ошибкой.
- Если в браузере выключен JavaScript, сайт просит его включить.
