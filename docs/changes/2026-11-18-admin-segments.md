# Переключатели в админке: варианты видны отдельно

- В переключателях админки на компьютере (сроки в «Выдать подписку», трафик в «Изменить лимиты», фильтры и периоды) у каждого варианта тонкая рамка и отступ, выбранный по-прежнему залит. Перенос на вторую строку больше не сливается в один ряд текста.
