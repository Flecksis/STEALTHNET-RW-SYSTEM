# Исходящий прокси: направление «Капча антибота»

- В «Настройки → Общие → Исходящий прокси» появилось направление «Капча антибота»: проверка ответов капчи у Cloudflare или Яндекса пойдёт через прокси. Пригодится, если сервис капчи не открывается с сервера панели.
- По умолчанию направление выключено, после обновления ничего не меняется. В `deploy/.env` оно называется `captcha`.
- Если прокси не отвечает, проверка капчи не проходит мимо него: клиенты видят просьбу повторить, а причина видна на странице «Антибот».
