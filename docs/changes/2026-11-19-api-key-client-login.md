# Ключам API больше не выдаются «Вход за клиента» и синхронизация

- В «Настройки → API-ключи» больше нельзя отметить «Вход за клиента». «Синхронизацию с Remnawave» ключу тоже не выдать.
- Если у ключа это право уже было, оно перестаёт действовать: ключ больше не может сбросить клиенту вход по коду (2FA) или отвязать почту. Остальные права ключа работают как раньше.
- Если ваш скрипт или интеграция делали это ключом, делайте это в админке под своей учётной записью.
