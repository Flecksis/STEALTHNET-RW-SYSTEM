# Лендинг называет цену вместо «Подключитесь сегодня»

- Если пробный период выключен, последний блок лендинга называется по самой низкой цене в месяц среди тарифов в продаже, например «От $2.00 в месяц», а не «Подключитесь сегодня». Пока тарифов в продаже нет — «Оформите подписку». Заголовок, заданный в «Настройки → Лендинг», не меняется.
- Мини-приложение: пока оператор не сохранил настройки рулетки, клиент видит «Рулетка ещё не настроена.» вместо обещания «Рулетка скоро заработает — загляните позже.»
