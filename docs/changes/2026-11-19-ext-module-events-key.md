# События внешним модулям — только с действующим ключом

- Внешний модуль не получает события, если его ключ API отозван или истёк или администратор, который выпустил ключ, отключён.
- Если у этого администратора забрали право, нужное событию (например, «Деньги» для оплат), такие события модулю тоже не уходят, остальные приходят как раньше.
- События, которые уже ждали отправки, в этом случае не отправляются: в журнале модуля видна причина. После выпуска нового ключа их можно отправить снова кнопкой «Отправить снова».
