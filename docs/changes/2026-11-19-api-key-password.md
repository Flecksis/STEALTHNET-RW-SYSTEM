# Ключ API выпускается с паролем и гаснет при сбросе

- Чтобы выпустить API-ключ, нужно ввести свой пароль, а если включён вход по коду — ещё и код из приложения. Уже выпущенные ключи продолжают работать.
- Когда владелец выдаёт администратору новый пароль или сбрасывает ему 2FA, API-ключи, которые выпустил этот администратор, отзываются. Ключи внешних модулей не трогаются.
- Если ваш скрипт работает на ключе такого администратора, выпустите новый ключ и замените его в скрипте.
