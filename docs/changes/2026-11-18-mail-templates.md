# Шаблоны писем

- В «Настройки → Почта и уведомления» появилась вкладка «Шаблоны писем»: тему, текст и кнопку каждого письма клиенту можно поменять на русском и английском. Подстановки вроде даты и тарифа вставляются кнопкой, рядом виден предпросмотр письма, проверочное письмо можно отправить себе.
- Общее оформление писем: логотип и цвет кнопок берутся из «Оформления», имя отправителя и подпись внизу письма задаются на этой вкладке. Выключатели групп писем переехали сюда из «Отправки».
- Коды для входа, смены пароля и смены почты теперь приходят оформленными письмами, код крупный. Тексты писем больше не повторяют тексты уведомлений бота — у писем свои.
- Исправлено: о пополнении баланса клиент теперь получает уведомление в бот или письмом; письма о повторной оплате по уже оплаченному счёту доходят клиентам без Telegram; напоминание перед автопродлением приходит с темой «Пополните баланс для автопродления», а не «Подписку не удалось продлить».
