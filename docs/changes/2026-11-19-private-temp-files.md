# Временные файлы переноса и загруженных копий закрыты от других пользователей сервера

- Файл старого бота при переносе и загруженная для восстановления копия теперь доступны только пользователю, от которого работает панель. Это важно, если панель установлена без Docker и на сервере есть другие пользователи.
- Если папку для переноса (`SN_IMPORT_DIR`) создал другой пользователь системы, панель откажется туда писать и скажет об этом. Удалите такую папку или укажите другую.
- При запуске панель удаляет из папки переноса только свои временные файлы. Если эта папка совпадает с папкой резервных копий, копии больше не пропадут.
