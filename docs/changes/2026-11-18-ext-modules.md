# Свои модули из файла

- В «Модулях» появилась кнопка «Установить модуль»: загружаете файл описания от автора модуля, видите, какие события и права он получит, и подтверждаете.
- Модуль — отдельная программа на вашем сервере. Панель не запускает её код: шлёт ей события с подписью и выдаёт ключ API только с подтверждёнными правами, не шире ваших. Ключ и секрет показываются один раз.
- В карточке модуля: включение и выключение, настройки, страница модуля внутри админки, проверка связи и журнал доставки событий с повторами.
- Обновление из нового файла просит подтвердить права заново, удаление сразу отзывает ключ модуля.
- Как написать свой модуль — в docs/MODULES.md, рабочий пример — в examples/module-hello.
