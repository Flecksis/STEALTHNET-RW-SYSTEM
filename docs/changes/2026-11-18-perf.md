# Панель быстрее на больших базах

- Карточка клиента открывает историю быстрее: лента больше не перебирает весь журнал действий панели.
- Поиск клиентов по почте, @username, номеру Telegram и словам отвечает быстро, даже когда ничего не найдено.
- Охват рассылки считается в разы быстрее, а авторассылки не замедляются после включения нового правила.
- Аналитика, список тарифов и очередь поддержки открываются быстрее на базах с сотнями тысяч оплат.
- При обновлении панель построит несколько новых индексов: на базе с миллионом оплат это занимает около 5 секунд.
