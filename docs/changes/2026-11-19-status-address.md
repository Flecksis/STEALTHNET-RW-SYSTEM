# stealthnet status показывает адрес панели

- `stealthnet status` показывает адрес панели, который задан при установке или командой `stealthnet domain`. Если адреса нет, так и написано, с командой, которой его задать.
- Так сразу видно, почему письма, уведомления платёжек и ссылки в боте не работают на панели, которая открывается по домену, но поставлена без него.
