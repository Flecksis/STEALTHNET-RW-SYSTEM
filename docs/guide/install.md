# Установка, обновление и резервные копии

## Что нужно

- Сервер на Linux с Docker. Если Docker нет, установщик предложит поставить его сам (при запуске от root) или покажет команду.
- Домен для панели, например `panel.example.com`, направленный на этот сервер. Без домена установка тоже пройдёт, домен можно указать позже командой `stealthnet domain`.
- Свободные порты 80 и 443, если сертификат должен выпустить установщик. Если их держит другая программа, например nginx панели Remnawave, читайте ниже «Порты 80 и 443 заняты».

Готовая сборка выпускается для процессоров x86_64. На ARM установщик соберёт систему из исходников, это 10–20 минут.

## Установка

Скопируйте команду целиком и выполните на сервере:

```sh
git clone https://github.com/STEALTHNET-APP/STEALTHNET-RW-SYSTEM.git && STEALTHNET-RW-SYSTEM/install.sh
```

Установщик спросит домен панели и почту владельца. Дальше он сам:

1. создаст пароль базы и ключ шифрования и запишет их в `deploy/.env`;
2. скачает готовую сборку и запустит панель и базу в Docker;
3. выпустит сертификат HTTPS для домена (Caddy, продлевается сам);
4. создаст владельца и покажет адрес панели, почту и пароль.

Пароль владельца показывается один раз, сохраните его. Повторный запуск `install.sh` продолжает установку и ничего не перезаписывает.

Установка без вопросов, например из своего скрипта:

```sh
SN_OWNER_EMAIL=owner@example.com SN_DOMAIN=panel.example.com STEALTHNET-RW-SYSTEM/install.sh
```

Собрать из исходников вместо готовой сборки: `SN_BUILD=1 STEALTHNET-RW-SYSTEM/install.sh`.

### Что установщик решает сам

- Порт 8080 занят — берёт следующий свободный, до 8099, и показывает его в конце. Панель слушает только `127.0.0.1`, снаружи её видно через HTTPS.
- На сервере уже стоит Remnawave — подключает панель к сети `remnawave-network`. Тогда в «Настройки → Remnawave» адрес панели — `http://remnawave:3000`, а защиту eGames указывать не нужно: запросы идут к Remnawave напрямую, мимо nginx и Caddy.
- Установка от root на сервере с systemd — ставит помощника обновлений, и обновлять можно из админки. Без него обновление делается командой `stealthnet update`.

### Порты 80 и 443 заняты

Если порты держит другая программа, установщик ничего в ней не меняет. Он кладёт в `deploy/proxy-snippet.txt` готовый блок для Caddy и nginx и в конце говорит об этом. Добавьте блок в свою программу и перезагрузите её.

В блоке для nginx уже есть `client_max_body_size 2g`, чтобы при переносе прошла копия старого бота до 2 ГБ, и заголовок `X-Forwarded-For`. Если в журнале входов и у клиентов вместо их адресов виден адрес прокси, настройте `SN_TRUSTED_PROXIES` (см. [переменные окружения](../../README.md#переменные-окружения)).

## Команда `stealthnet`

После установки команда работает из любой папки. Если поставить её не удалось (нет прав на `/usr/local/bin`), установщик покажет те же действия с полным путём: `STEALTHNET-RW-SYSTEM/install.sh --update` и т. д.

| Команда | Что делает |
|---|---|
| `stealthnet` | Установить или продолжить установку |
| `stealthnet domain` | Указать или сменить домен панели |
| `stealthnet owner-email` | Сменить почту владельца, пароль остаётся прежним |
| `stealthnet reset-password` | Выдать владельцу новый пароль, все его сессии закрываются |
| `stealthnet unlock-login`, `stealthnet unlock-login --ip <адрес>` | Снять блокировку входа владельца, если его почту подбирают. С `--ip` вход с этого адреса не закроется 30 дней, даже пока подбор идёт |
| `stealthnet update` | Скачать новую версию и обновить систему |
| `stealthnet status` | Показать версию, состояние панели и итог последнего обновления |
| `stealthnet helper on`, `stealthnet helper off` | Разрешить или запретить обновление из админки |
| `stealthnet start`, `stealthnet restart`, `stealthnet stop` | Запустить (например, после перезагрузки сервера), перезапустить или остановить систему |
| `stealthnet logs`, `stealthnet logs -f` | Последние строки журнала панели; с `-f` — следить |

## Обновление

### Из админки

Раз в сутки панель спрашивает у реестра сборок GitHub, вышла ли новая версия. Когда вышла, у «Настроек» появляется точка, а в «Настройки → Обновления и резервные копии» — кнопка обновления.

Обновляет только владелец: панель ещё раз спрашивает пароль и, если включён вход по коду, код из приложения. Шаги видны на экране: «Проверка сборки», «Загрузка», «Резервная копия», «Обновление базы», «Запуск новой версии», «Проверка работы». Панель и бот недоступны около минуты, страницу можно не закрывать — она продолжит сама.

Само приложение Docker не трогает: оно кладёт заявку, а обновляет помощник на сервере. Поэтому на экране может появиться просьба выполнить команду. Панель просит только две команды: `sudo stealthnet status` и `sudo stealthnet update`. Другие команды от имени панели не выполняйте.

### Командой

```sh
sudo stealthnet update
```

Команда идёт тем же путём, что и админка. Ею можно обновляться всегда, даже если обновление из админки выключено.

### Что происходит при обновлении

1. Скачивается новая сборка, проверяется её номер.
2. Панель останавливается, сохраняется копия базы и файла `deploy/.env`.
3. Новая версия обновляет копию базы, затем копия становится рабочей базой.
4. Запускается новая версия, 90 секунд проверяется, что отвечают панель, бот и фоновые задачи.

Если сбой случился до запуска новой версии, возвращается прежняя версия на нетронутой базе. После запуска база назад сама не возвращается: за это время могли прийти оплаты. В таком случае `stealthnet status` и экран обновлений покажут, что случилось и что делать.

Проверку обновлений можно выключить в том же экране или переменной `SN_UPDATE_CHECK=false` — например, если у сервера нет выхода в интернет.

## Резервные копии

Перед каждым обновлением сервер сам сохраняет копию базы и файла `deploy/.env` в папку `deploy/backups`. Хранятся три последние копии: файл базы `.dump` и рядом `.env` с тем же именем.

Скачать копию из админки нельзя: с ключом из `.env` расшифровываются токены платёжных систем и бота. Храните копию не только на этом сервере и никому её не отправляйте.

Главное, что нужно сохранить отдельно, — файл `deploy/.env`. В нём `SN_SECRET_KEY`: без него не расшифровать ключи платёжных систем, токены и пароли, введённые в админке.

Свою копию базы в любой момент можно снять так же, как это делает обновление:

```sh
cd STEALTHNET-RW-SYSTEM/deploy
docker compose exec -T postgres pg_dump -U stealthnet -d stealthnet -Fc > stealthnet.dump
```

Копия не останавливает панель. Положите рядом копию `.env` и перенесите обе туда, где их не потеряете.
