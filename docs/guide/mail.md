# Почта и шаблоны писем

Почта нужна для входа на сайт по почте, кодов, напоминаний и уведомлений тем клиентам, кому нельзя написать в Telegram, и для рассылок на почту. Работает модуль «Почта», настройка — «Настройки → Почта и уведомления». Если модуль выключен, письма не отправляются, а вход по почте работает только по паролю.

## Отправка

Вкладка «Отправка», поле «Отправка писем»:

- **Не отправлять** — письма не уходят: ни коды, ни напоминания. Клиенты из бота не смогут привязать почту для входа на сайт: кнопки «Вход по почте» в боте не будет.
- **SMTP** — через ваш почтовый сервер: Яндекс, Mail.ru, Gmail или свой. Поля: сервер SMTP (например `smtp.yandex.ru`, `smtp.mail.ru` или `smtp.gmail.com`), шифрование, порт (пусто — 587 для STARTTLS, 465 для TLS), логин (обычно адрес почты, с которой идут письма), пароль. Для Яндекса, Mail.ru и Gmail нужен пароль приложения, а не пароль от почты.
- **Resend API** — через сервис Resend. Ключ API начинается с `re_`, его выдают в кабинете resend.com. Домен адреса отправителя должен быть подтверждён в Resend.

**Адрес отправителя** клиенты увидят в поле «От».

Если поменять сервер SMTP, порт, шифрование или логин, пароль нужно ввести заново в том же сохранении: панель не отправляет сохранённый пароль на другой сервер или под другим логином. Ключ Resend уходит только в сам Resend.

Нажмите «Отправить проверку» и впишите свой адрес, чтобы убедиться, что сервис принимает настройки и письма доходят.

### Вход на сайт по почте

Вход в кабинет по почте вместо Telegram:

- **По паролю** — регистрация с паролем, забытый пароль меняется по коду из письма. Если письма не отправляются, новый пароль выдаёт администратор в карточке клиента («Новый пароль для сайта», нужно право «Вход за клиента»).
- **По коду из письма** — пароль не нужен, при каждом входе на почту приходит код.

Код из письма — 6 цифр, действует 15 минут. Если на одну почту за сутки ввели 30 неверных кодов, вход по коду на эту почту закрывается примерно на сутки. После «Прислать код» кабинет пишет, на какой адрес ушёл код. «Отправить ещё раз» становится доступна через минуту (не больше трёх писем на адрес за 15 минут), «Изменить почту» возвращает к вводу адреса.

Если клиент зарегистрировался по паролю, почту при этом не подтверждал, а потом вошёл кодом из письма, прежние входы на сайте закрываются, а пароль удаляется. Понадобится вход по паролю — пароль задаётся заново через «Забыли пароль».

### Почта у клиентов из бота

Клиентам из бота почта нужна, чтобы войти в кабинет на сайте, если Telegram не работает. Привязать её можно тремя способами:

- **В боте** — кнопка «Вход по почте» в главном меню. Клиент присылает адрес, получает на него код и присылает код в бот. При входе по паролю бот сразу просит задать пароль: кнопка «Задать пароль» открывает экран пароля в мини-приложении. Если мини-приложение выключено, пароль присылают в чат: бот сразу удаляет сообщение с паролем и предупреждает, что текст может остаться в уведомлениях на телефоне. В конце бот пишет, где и как входить по почте. Кнопка видна, когда письма отправляются, вход на сайт открыт («Настройки → Кабинет и мини-приложение») и у панели есть адрес сайта (задаётся командой `stealthnet domain`). Убрать её можно в «Настройки → Бот», вкладка «Тексты и кнопки», раздел «Главное меню», или в карточке кнопки на вкладке «Порядок кнопок».
- **В мини-приложении** — «Профиль» → «Почта». После подтверждения почты появляется кнопка «Задать пароль».
- **В кабинете** — «Безопасность» → «Почта». После подтверждения почты кабинет предлагает задать пароль в карточке «Пароль».

Если у клиента включён вход по коду из приложения (2FA) или уже есть пароль, для смены почты нужен этот код или пароль. Пароль бот спрашивает в мини-приложении, а если оно выключено — в чате, с тем же удалением сообщения.

Без Telegram клиент входит на странице кабинета: вкладка «Почта», адрес и пароль. Забытый пароль меняется по ссылке «Забыли пароль?» кодом из письма. При входе по коду из письма пароль не нужен.

### Почта в карточке клиента

В карточке клиента в блоке «Профиль» у строки «Email» есть кнопка «Изменить» (если почты нет — «Указать»). На телефоне — «Ещё» → «Изменить почту». Нужно право «Вход за клиента».

- **Сохранить** — почта заменяет прежнюю без кода подтверждения: панель считает её подтверждённой, поэтому проверьте адрес. Пароль для сайта остаётся прежним, входы в кабинет на сайте закрываются, мини-приложение продолжает работать. Клиенту приходит сообщение в бот, на прежний адрес — письмо «Почта изменена».
- **Отвязать почту** — почта и пароль для сайта отвязываются, войти по почте больше нельзя. Входы в кабинет на сайте закрываются, клиенту приходит сообщение в бот. Если клиент входит только по почте, отвязать её нельзя: укажите вместо неё другую.

Если такая почта уже есть у другого клиента, панель не сохранит её и покажет ссылку «Открыть карточку». Смена и отвязка почты записываются в историю клиента.

## Шаблоны писем

Вкладка «Шаблоны писем» — темы и тексты писем, которые панель отправляет клиентам сама. Рассылки пишутся в разделе «Рассылки».

### Группы писем

| Группа | Можно выключить | Письма |
|---|---|---|
| Вход и почта | нет | Коды для входа, смены пароля и смены почты |
| Оплата и подарки | да | Подписка готова или продлена, баланс пополнен, деньги зачислены на баланс, оплату проверим вручную, оплата или звёзды возвращены, подарок оплачен или активирован |
| Автопродление | да | Не хватает на автопродление, автопродление не прошло, продлите вручную, автопродление выключено |
| Поддержка | да | Ответ поддержки со ссылкой на переписку в кабинете |
| Безопасность и трафик | нет | Привязан вход через Google или Apple, почта изменена, превышен лимит трафика, доступ ограничен или ограничение снято, новая ссылка на подписку после переноса в Remnawave |

Письма об оплате, автопродлении и поддержке получают клиенты, которым нельзя написать в Telegram. Напоминания о конце подписки делаются автоматическими рассылками в разделе «Рассылки».

### Редактор

- У каждого письма можно поменять тему, текст и надпись кнопки, отдельно на русском и на английском. Пустое поле — стандартный текст. Английские письма получают клиенты, которые выбрали английский.
- Подстановки вроде `{date}` или `{code}` вставляются кнопкой, во всех письмах есть `{brand}` и `{email}`. Разметка текста — как в текстах бота.
- Справа предпросмотр на выдуманных данных, «Отправить себе» пришлёт это письмо на ваш адрес.
- «Оформление писем»: имя отправителя (так письма подписаны в поле «От») и подпись внизу письма, у английских писем подпись своя. Логотип и вид кнопок — как в кабинете, меняются в «Настройки → Оформление».

Если у панели не задан адрес сервиса («Настройки → Общие → Адрес сервиса»; домен задаётся при установке или командой `stealthnet domain` на сервере), служебные письма уходят без кнопок и логотипа, а рассылки по почте не отправляются: в каждом таком письме нужна ссылка «Отписаться».

Панель проверяет шаблон при сохранении: неизвестную или неверно записанную подстановку, пропущенный `{code}` в письмах с кодом, длину темы (150 знаков), текста (4000) и кнопки (40).
